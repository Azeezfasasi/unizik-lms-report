# UNIZIK LMS Portal User Guide

This guide is for non-technical users who need to operate the portal and navigate its main features.

## What this portal does

The UNIZIK LMS Portal helps postgraduate staff and students manage academic reporting, departments, curricula, and examination activities.

## Accessing the portal

1. Open your browser.
2. Go to the portal URL provided by your institution.
3. Enter your email and password on the login page.
4. Click **Log in**.

If you forget your password, use the **Forgot password?** link to reset it.

## Main pages

After login, you land on the **Dashboard**. This is the welcome page for the portal.

### Dashboard

The Dashboard shows:
- total number of faculties
- total number of curricula
- total number of students
- number of submitted reports
- recent examiner activity
- quick action buttons for common tasks

Use the Dashboard to get a quick overview of the system.

### Faculty & Departments

Use this section to manage the academic structure of the school.
- Add new faculties
- Add new departments under faculties
- Edit existing faculty and department details

### Curriculum

Use this area to manage programs and course structures.
- View existing curricula
- Add new curriculums
- Edit curriculum details

### Examiner Reports

This section is for managing examiner report submissions.
- View list of examiner reports
- Open report details
- Review report status and notes

### Student Reports

Use this section to manage student-related reporting.

### Submitted Reports

This is a summary of reports that have already been filed and submitted.

### Students

Use this section to manage student records.
- Add new students
- Edit student details

### Users

This page is for admin users to manage user accounts.
- View user list
- Add or edit users

### Settings

Use this page to update your profile information.
- View your account details
- Update profile settings

## How to navigate

The left sidebar is the main menu for the portal.

- Click a menu item to go to that section.
- The current page is highlighted.
- If you do not see a menu item, it may be restricted by your account role.

## Common tasks

### 1. Log in
- Enter your registered email.
- Enter your password.

### 2. Reset password
- Click **Forgot password?** on the login page.
- Follow the instructions sent to your email.

### 3. View the dashboard
- Click **Dashboard** in the sidebar.
- Review cards for faculties, curricula, students, and reports.

### 4. Add a new department
- Go to **Faculty & Departments**.
- Select the faculty.
- Use the **Add department** action.

### 5. Add a new curriculum
- Go to **Curriculum**.
- Choose **Add curriculum**.
- Complete the form and save.

### 6. Review examiner reports
- Go to **Examiner Reports**.
- Click a report to view details.
- Review the status and notes.

## Roles and permissions

The portal adjusts what you can see based on your role.

- **Admin** users see everything.
- **Faculty officers** see academic and reporting tasks.
- **Examiners** see report creation and review features.
- **Students** see student reporting and personal settings.

If you cannot access a page, contact your system administrator.

## Tips for using the portal

- Use the sidebar to switch sections.
- Look for buttons labeled **Add**, **Create**, **Edit**, or **View**.
- If a page is blank or does not load, refresh the browser.
- If you are unsure where to go, start at the Dashboard.

## Need help?

If you encounter errors or cannot find a feature, contact the portal support team or system administrator.

This guide is meant to help you use the portal without technical knowledge.
